# LA VILLA — Modern Pâtisserie Website

A responsive, premium static website inspired by the elegant cream/gold pastry aesthetic in the reference image.

## Files
- `index.html` — structure/content
- `styles.css` — complete responsive design
- `script.js` — mobile menu, scroll reveal, current year
- `assets/` — place your local images/logo here if desired

## Run locally
Simply open `index.html` in Chrome/Edge/Firefox.

For development, you can also use VS Code + Live Server.

## Put it on GitHub Pages
1. Create a new GitHub repository, for example `lavilla-patisserie`.
2. Upload `index.html`, `styles.css`, `script.js`, and the `assets` folder.
3. Open the repository → **Settings** → **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.
7. GitHub will give you a public `github.io` URL.

## Customize
Replace:
- business name
- phone
- email
- Instagram
- address
- product names/descriptions
- Unsplash image URLs in `styles.css`

For a fully independent site, download your preferred images into `assets/` and change the CSS URLs to local paths such as:
`url("assets/hero.jpg")`

No backend, database, or paid hosting is required for the static version.
